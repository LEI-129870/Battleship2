## 3. Reflexão sobre as Limitações do Checkstyle

O Checkstyle é uma ferramenta extremamente útil e eficaz para validar padrões estruturais de código em Java através de expressões regulares, garantindo que o código mantém uma formatação consistente em toda a equipa.

No entanto, a ferramenta apresenta limitações claras ao nível da análise semântica e do contexto de negócio:
1. **Falta de verificação semântica:** O Checkstyle valida se a constante cumpre o padrão estipulado (ex: letras maiúsculas), mas não avalia se o valor atribuído ou o nome escolhido fazem sentido no contexto do domínio da aplicação (por exemplo, aceitaria uma constante mal nomeada ou com um valor inadequado desde que respeitasse a sintaxe).
2. **Ausência de contexto de negócio:** A ferramenta foca-se exclusivamente na forma estrutural do identificador, sendo incapaz de detetar se a escolha do nome reflete corretamente a regra de negócio associada.
